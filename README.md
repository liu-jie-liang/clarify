# Clarify

把脑子里一团模糊的想法，转成一段干净的新会话开场文本。

## 什么时候用

你有一个问题，但说不清楚。或者你之前试过了，表述不好导致 AI 误解，浪费了一整轮会话。开新会话，调 clarify，它帮你理清楚。

**永远在新会话调用。不要在任何任务会话内调用。**

## 安装

```bash
cp -r clarify ~/.trae/skills/
```

## 使用

```
Use Skill: clarify

[只写你的问题]
```

不需要加"先生成文本""先问我几个问题"——clarify 自动追问，自动生成。你只描述问题，不需给指令。它追问到你理解一致，然后生成一段粘贴即开始的新会话开场文本。

## 和 ask-coach 的区别

| | clarify | ask-coach |
|---|---|---|
| 适用场景 | 任何新问题 | 仅 learning-coach 教学会话的沟通事故 |
| 绑规则 | 否 | 是（读 RULES.md + GATE_RULES.md） |
| 输入 | 你的模糊想法 | 你和 AI 的沟通事故 |

如果是教学会话遇到问题 → 用 ask-coach。遇到任何其他新问题说不清楚 → 用 clarify。
